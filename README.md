# Shivam Thakur — Portfolio Website

A responsive personal portfolio website with a cinematic dark/neon-green style.

## Included
- `index.html` — website source (HTML, CSS, JavaScript)
- `assets/shivam-profile.jpeg` — profile photo
- `assets/resume.pdf` — downloadable resume
- `assets/portfolio-scroll-video.mp4` — hero video scrubbed by scrolling

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example, `shivam-portfolio`).
2. Upload **all files and folders inside this package** to the repository root. Keep `index.html` at the root and retain the `assets/` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your website will be available at `https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`.

## Notes
- The website uses Google Fonts and GSAP via CDN, so animations/fonts require an internet connection. The page itself is static and GitHub Pages compatible.
- The hero video is included and scrubs forward or backward as you scroll through the opening section. Keep `assets/portfolio-scroll-video.mp4` with the site when publishing.
- Project cards are presented as learning/concept work. Replace their links/details with actual repository/demo URLs as your projects are completed.
- Contact form prepares an email draft using your email app; it does not send messages through a backend.
